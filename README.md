# DeepSeek 鲸鱼娘 · Discord 群友机器人

一个在自己电脑上运行的中文 Discord 文字聊天机器人：被 @ 或回复时会回答，在短时间内能接上自然追问，也会按设定的概率偶尔插话。支持多个服务器和文字频道、近期上下文、本地整理的长期记忆，以及本机费用估算上限。另有完全不调用大模型的计算、随机工具、提醒、互动、投票、签到、小游戏、便签和日期提醒；可以切换为纯本地模式。

> 这是自托管项目。下载代码不会自动让机器人上线；你的电脑、网络和程序都需要保持运行。只处理在配置窗口中选中的**服务器文字频道**，不处理私信、语音、帖子或未选中的频道。

## Windows 使用教程

### 1. 下载并准备 Python

1. 点击本仓库的 **Code → Download ZIP**，解压到你有写入权限的文件夹。
2. 安装 Python 3.11 或更新版本，并在安装时勾选 **Add Python to PATH**。项目在 Windows 的 Python 3.14 环境做过测试。
3. 双击 `configure.cmd`。首次打开会自动建立 `.venv` 并安装 `requirements.txt` 中的依赖，可能需要几分钟。

更新已有安装时，先在项目文件夹执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt`，再保存并重启机器人。Wordle 图片棋盘新增了 Pillow 依赖。

### 2. 创建 Discord 机器人

1. 打开 [Discord Developer Portal](https://discord.com/developers/applications)，创建一个 Application。
2. 在 **Bot** 页生成或重置 **Bot Token**，暂时保存在安全的地方。这里需要的是 Bot Token，不是 General Information 页的 Public Key。不要把 Token 发到群里或提交到 GitHub。
3. 仍在 **Bot** 页开启 **Message Content Intent**，保存设置。本项目需要读取普通频道消息才能续聊和偶尔插话。
4. 在 **Installation** 页启用 **Guild Install**。给 Guild Install 添加 `bot` scope，并选择 **View Channels**、**Send Messages**、**Read Message History** 三项权限；不需要 Administrator 权限。复制安装链接，通过 **Add to server** 把机器人安装到你管理的服务器。每个要使用的服务器都要安装一次。

### 3. 填写模型和频道

1. 在配置窗口的 **模型与预算** 页填写自己供应商的 **API 地址、API 密钥、模型名称**。支持返回 `choices[].message.content` 的 Chat Completions 兼容接口；不绑定 Inferera。地址应按供应商文档填写并保留 `/v1` 等路径，例如 `https://你的接口域名/v1`；也可直接粘贴完整的 `/chat/completions` 地址，程序会自动去掉末尾这一段。不会自动补 `/v1`。原生 Claude Messages 或 Gemini generateContent 接口需要使用供应商提供的兼容入口或兼容代理。
2. 模型名称可以自由输入，也可点击 **读取模型列表（可选）** 后下拉选择。供应商没有 `/models` 接口或列表里没显示模型时，仍能手动填写并保存。读取列表不会发送聊天请求。
3. 根据供应商的实际单价填写输入、输出的**每百万 tokens 价格**，选择 **人民币 (CNY)** 或 **美元 (USD)**；美元价格会使用填写的汇率转换为人民币。每日预算始终按人民币计算，默认 ¥2。免费接口的单价填 `0`，仍有每日调用次数限制。模板保留原 Inferera 默认值；换供应商或模型时务必同时核对价格。
4. 在 **Discord 频道** 页粘贴 **Discord Bot Token**。密钥只写入本机 `.env`；`config.json` 保存接口、频道和费用设置。这两个文件都被 `.gitignore` 排除。
5. 点击 **自动读取服务器和频道**，跨服务器勾选允许机器人活动的文字频道，再点击 **保存配置**。如果没有列出某个服务器，先确认机器人已通过安装链接加入。也可以手动填写 `服务器ID: 频道ID, 频道ID`，每行一个服务器。
6. 如需指定“主人”，可填写自己的 Discord 用户 ID；留空时，拥有服务器管理权限的人仍可使用暂停和恢复命令。无需设置主人也能正常聊天。

只想使用本地功能时，在 **本地功能** 页取消勾选“开启云端聊天”，可以留空大模型 API 密钥。Discord Bot Token 和频道配置仍需填写。该页还可以分别关闭每类功能；这些全局开关由所有服务器共用，各服务器管理员另可在频道里调整本服务器的开关。

配置窗口会验证 Token、服务器成员身份和所选频道的历史读取权限。保存配置后会生成你自己的 `config.json`，不会修改仓库里的 `config.example.json`。

远程接口使用 HTTPS，本机接口支持 `http://localhost:端口/v1`、`http://127.0.0.1:端口/v1` 或 IPv6 回环地址。本机服务没有鉴权时可以留空密钥。这里更改的是聊天模型接口；整理长期记忆仍使用独立的本地 Ollama，不会因此自动花费云端总结额度。

**附加参数** 页可填写 JSON 请求参数。普通接口默认 `{}`；Inferera 自动保留 `{"thinking":{"type":"disabled"}}`。更换地址时，尚未自定义的默认参数会随接口切换；自己改过的参数请按新供应商要求核对。例如 `{"temperature":0.6}` 修改温度，`{"temperature":null}` 移除温度参数。模型、消息、输出上限和流式开关由机器人控制，不能通过附加参数覆盖。接口应支持 `max_tokens` 和非流式聊天回复。

### 4. 启动和测试

在配置窗口点击 **保存并重启机器人**，程序会应用设置并在后台启动；若本机已配置本项目的登录启动任务，会通过该任务重启。也可双击 `start.cmd` 并保持窗口打开。在已勾选的频道发送 `!鲸鱼 状态`，确认机器人在线；再 @机器人说一句话。每次修改接口、频道、费用或 `persona.txt` 后都需要重启。一个电脑上只应运行一个实例。

机器人只响应**启动之后**的新消息，不会补答旧消息。电脑休眠、关机或断网时不会回复。本项目没有自动配置开机启动。

## 可选：本地整理长期记忆

配置窗口勾选“记录已选频道消息，并用本地 Qwen 定时整理记忆”后，机器人会把已选文字频道的新消息记在本机。直接与鲸鱼娘的对话会保留较细的摘要；她旁观的群聊只留一句简短印象。短摘要积累后，本地模型按人物和事件压缩为长期记忆。回复时只检索与当前话题有关的少数条目，避免把整份聊天记录发给云端。默认关闭，现有用户可自行启用。

本地总结需要先安装 [Ollama](https://ollama.com/download/windows)，再在终端运行 `ollama pull qwen3.5:2b-q4_K_M` 下载约 1.9GB 的模型。模型仅通过 `127.0.0.1` 的本机接口使用，不会自动调用收费的云端接口做总结。更改模型可修改本机 `config.json` 的 `local_memory_model`。在 16GB 内存的测试电脑上，4B 模型首次总结超时，因此默认采用较轻的 2B 量化模型。

整理在对话暂时安静后进行。程序会先检查接电状态、可用内存、显存、GPU 使用率和是否有全屏程序；条件合适才显示带提示音的小窗口，15 秒后默认开始。可以点“延后30分钟”“延后2小时”或“今天暂停”。整理按小批次执行，资源变紧时暂停；原始消息继续积压，下次再处理。`!鲸鱼 记忆状态` 可查看待整理条数。电脑一直忙、本地模型未安装或总结失败时，聊天照常运行，只是自动记忆更新较慢。

自动记忆在**同一服务器的公开频道间共享**，服务器之间隔离。只有原频道能使用受限频道的记忆，避免把私密讨论带到公开频道。最近几条原文仍仅取当前频道，防止把别处的“刚才”误当成当前话题。用户可用 `!鲸鱼 清空记忆` 清除本人在整个服务器的记录和相关摘要，或用 `!鲸鱼 关闭记忆` 同时停止今后的记录。手动保存的记忆继续可用；它们在公开频道之间共享，来自受限频道的条目仍只在原频道使用。

## 它什么时候会说话？

- **被 @ 或回复机器人：** 直接回答，不受普通插话概率和冷却限制。
- **连续对话：** 机器人回答后，约两分钟内会判断同一位群友的新消息是否在接着和它说话；不必每句都 @。无关消息可以不回答，这种判断可能消耗一次模型调用。
- **普通插话：** 默认需要该频道累计至少 5 条消息、距上次回答至少 3 分钟；之后通常每条约 12% 概率触发，鲸鱼或米饭等相关话题概率可更高。其他频道正在聊天不会阻断本频道，但每日上限由所有频道共用。

日常回复尽量保持 3—20 个汉字；解释、教学和解题可以更长。只有服务器存在代码支持的自定义表情时，才会偶尔附一个；每个服务器只使用自己的表情。

使用 Discord 的「回复」功能时，模型会优先结合被引用的消息理解当前发言，倒赞等纯表情也会沿该对话回应。明确引用及其上一级引用可超过普通近期上下文默认的 20 分钟期限，仍只读取当前频道，并继续遵守关闭记忆、清空记录和本地工具排除规则；普通旁观消息依照原期限过期。相关记忆也围绕被引用的话题检索。引用已删除或无法读取且意思不清时，会提示问清楚，避免借附近的无关话题猜测。

同一位群友把一句话分成多条发送时，机器人会等最近一条之后约 2 秒的停顿再回答；最后一条是短词或单字时约等 3 秒。每次补发都会延长等待，连续发言最长等 12 秒，一轮最多收 32 条。中文小片段会连起来理解，例如“真／的／假／的”会变成“真的假的”；近期上下文也按连续发言合并，避免单字消息挤掉原来的话题。发给其他群友的明确回复或 @ 不会拼进当前问题。

合并在本机完成。若已经向云端发送请求后才补上后半句，机器人会收住过时的回复，再用完整发言更新回答；已发出的请求仍计入每日额度。等待时间和条数可通过本机 `config.json` 的 `reply_delay_seconds`、`reply_batch_max_wait_seconds`、`reply_batch_max_messages` 调整。

### 作文、翻译和长回答

“写一篇”“范文”“rumusan”“karangan”、翻译、详细讲解、“输出全文”“请背诵”“默写”等请求会进入长回答模式。正文按任务要求的语言和长度生成，不受日常 3—20 字的限制；默认每次允许输出 2048 tokens。长任务的输入也不会按普通闲聊的 1000 字符截短；如果原题实在超过本次输入预算，会明确提示缩短任务，而不会只处理前半段。此类任务优先于懒散、嘴硬的人设；若模型确实无法确定原文，会说明不确定之处，不把片段冒充全文。机器人目前没有自动检索校对原文的能力，逐字准确的全文仍应核对可靠来源。

正文在本机按段落、句子和单词分段，每条发送内容（含编号与格式）不超过 1900 个字符，表情长度保守计算；跨消息的代码块会关闭并重新打开。第一段回复提问，后续段落引用本批的第一段。分段不调用模型。超过 5 段会发送简短预览及完整 UTF-8 TXT 附件；缺少附件权限时，每批最多发 5 段，点击“补发剩余”或回复“补发”继续发送缓存，不消耗模型额度。

若模型报告正文尚未完成，默认在预算内自动续写一次；之后提供“继续写”按钮，也可以回复任意一段说“继续”。续写保留原题，仅带适量已写末尾，尽量避免重复与额外上下文费用；每次续写仍计入当天费用和调用次数。文本分段与模型截断分别处理，已生成内容先保存，发送失败后补发尚未送达的段落，不重新请求模型。已经完整完成的文章不会因重复点击旧按钮而重新生成。

原题、完整正文、发送进度和各段关联在本机保留 7 天（从最近更新起），重启后可恢复续写按钮；日常上下文将多段长文合并为一条简短记录，引用任意一段仍能定位原题。不同服务器和频道的长文分别保存。关闭记忆时只在本次进程内暂存，重启即清除；清空本人记忆、清空频道上下文或删除/编辑相关消息时，会清掉相应长文缓存。

桌面配置的“附加参数”页可设置长回答额度（256—8192 tokens）和自动续写次数（0 或 1），对应 `long_output_tokens` 与 `long_auto_continue`。额度须符合所用接口的能力；每日预算继续生效，不会因为选择长文模式而取消费用上限。附件需要 Discord 的 Attach Files 权限。

## 本地命令

所有命令都在已启用的频道发送，不调用大模型。

| 命令 | 作用 |
| --- | --- |
| `!鲸鱼 帮助` | 查看聊天与命令说明 |
| `!鲸鱼 状态` | 查看暂停状态、当日费用估算和调用次数 |
| `!鲸鱼 记住 称呼=小明` | 保存或更新自己在当前频道的一条记忆 |
| `!鲸鱼 记忆` | 查看自己主动保存、在本频道可用的记忆 |
| `!鲸鱼 记忆状态` | 查看自动摘要与待整理消息数量 |
| `!鲸鱼 忘记 称呼` | 删除一条记忆 |
| `!鲸鱼 清空记忆` | 清除自己在本服务器的原始记录、相关自动摘要和手动记忆 |
| `!鲸鱼 关闭记忆` / `!鲸鱼 开启记忆` | 清除并停止、或恢复本人的记录 |
| `!鲸鱼 暂停` / `!鲸鱼 恢复` | 管理员暂停或恢复当前频道聊天 |
| `!鲸鱼 清空上下文` | 管理员清除当前频道的短期上下文 |

手动记忆每人每频道最多 12 条。开启自动记忆后，还会从已选频道的聊天中生成摘要；请告知服务器成员。记忆命令的回复公开显示在频道内，不适合保存秘密。暂停状态仍按频道隔离，自动记忆在服务器内按频道可见性共享。

## 零 token 工具和互动

以下功能由程序和本地数据库处理，不调用聊天模型、Ollama 或其他数据服务，不计入模型调用次数或预算。模型接口不可用、当天聊天额度耗尽或管理员暂停聊天时仍能使用。功能关闭、参数错误和未知 `!鲸鱼` 指令只显示本地提示，不会转交模型。

| 用法 | 作用 |
| --- | --- |
| `!鲸鱼 工具`、`/鲸鱼 工具` | 查看用法，并显示掷骰、摸摸和投喂按钮 |
| `!鲸鱼 掷骰 2d6`、`!鲸鱼 掷骰 1d20+3` | 掷骰并计算总和，一次最多 20 颗 |
| `!鲸鱼 抽签 小明 小红 小蓝` | 从提供的不同名字中随机抽一人 |
| `!鲸鱼 选一个 米饭 面条 饺子` | 随机选择；名字含空格时用逗号分隔 |
| `!鲸鱼 计算 (12+8)*3` | 四则运算、括号、幂、`sqrt`、`abs`、`sin/cos/tan`、自然对数 `log`、`pi` 和 `e`；三角函数使用弧度 |
| `!鲸鱼 换算 100 cm m` | 长度、质量、容量、时间、温度和数据大小换算；例如 `32 华氏度 摄氏度`、`1 GiB MiB` |
| `!鲸鱼 提醒我 20分钟后 喝水` | 在原频道提醒本人；支持 `1小时30分钟` 等相对时间 |
| `!鲸鱼 倒计时 5分钟` | 到期提示倒计时结束 |
| `!鲸鱼 提醒列表`、`!鲸鱼 取消提醒 1` | 查看、取消本人在当前频道的提醒 |
| `!鲸鱼 摸摸`、`!鲸鱼 投喂` | 预设的温和短台词，偶尔附服务器表情；可点击按钮继续 |
| `!鲸鱼 签到`、`!鲸鱼 饭碗` | 每日领 10 粒米饭；新账户有 3 粒，投喂一次用 1 粒 |
| `!鲸鱼 猜数字`、`!鲸鱼 猜数字 50` | 猜 1—100 的整数，十次机会、十分钟有效；游戏中也可直接发数字 |
| `!鲸鱼 猜数字 重开`、`!鲸鱼 退出游戏` | 重开或退出自己的猜数字游戏 |
| `!鲸鱼 猜拳`、`!鲸鱼 猜拳 石头` | 石头剪刀布，也可点击出拳按钮 |
| `!鲸鱼 投票 今晚吃什么 \| 米饭 \| 面条` | 2—8 项单选投票；一人一票，可改选，计数自动更新 |
| `!鲸鱼 投票结果 1`、`!鲸鱼 结束投票 1` | 查询结果；发起人或管理员可结束本频道投票 |
| `!鲸鱼 便签 保存 书名=电磁学`、`!鲸鱼 便签 书名` | 保存、更新、查看本人的频道便签 |
| `!鲸鱼 便签列表`、`!鲸鱼 删除便签 书名` | 列出名称或删除自己的便签，每人每频道最多 20 条 |
| `!鲸鱼 群规 礼貌` | 按关键词查管理员已录入的说明，不做模型推断 |

| `!鲸鱼 生日 10-01` | 本人主动设置生日，只记录月日；每年原频道提醒 |
| `!鲸鱼 纪念日 相识=10-01` | 每年提醒自己的指定纪念日 |
| `!鲸鱼 取消生日`、`!鲸鱼 取消纪念日 相识` | 取消本人在当前频道的日期提醒 |
| `!鲸鱼 功能`、`!鲸鱼 开启功能 投票`、`!鲸鱼 关闭功能 投票` | 查看开关；管理员或主人修改本服务器开关 |

所有功能也提供 `/鲸鱼` 入口，配置的服务器会在启动时同步命令。便签在 `/鲸鱼 便签` 下，生日和纪念日在 `/鲸鱼 日期` 下，开关在 `/鲸鱼 功能` 下。斜杠命令的便签、饭碗和提醒列表等个人查询只向操作者显示；`!鲸鱼` 文字指令的回复显示在频道内。未选定的频道和私信不能使用这些功能。

使用 `/鲸鱼 投票` 时，分别填写「问题」「选项1」「选项2」；如需更多选项，再添加「选项3」至「选项8」。前两项必填，后六项可留空，不需要手动输入分隔符。问题和单个选项不能包含 `|` 或 `｜`。例如问题填“今晚吃什么”，选项1填“米饭”，选项2填“面条”。文字指令仍使用上表中的 `|` 分隔格式。

## 合作 Wordle 图片棋盘

普通模式猜 **5 字母**英文单词，全频道共享 **6 次**机会；超级模式猜 **7 字母**英文单词，全频道共享 **12 次**机会。每个已选文字频道同时只能有一局，所有群友都可参加，服务器和频道之间分别开局。普通聊天、讨论候选词不会自动提交猜测。

| 操作 | 斜杠命令 | 文字命令 |
| --- | --- | --- |
| 开局 | `/鲸鱼 wordle 开始`，模式下拉选普通或超级 | `!鲸鱼 wordle 开始 超级` |
| 猜词 | `/鲸鱼 wordle 猜`，填写单词 | `!鲸鱼 wordle 猜 cartoon` |
| 查看或恢复棋盘 | `/鲸鱼 wordle 状态` | `!鲸鱼 wordle 状态` |
| 提前结束 | `/鲸鱼 wordle 结束` | `!鲸鱼 wordle 结束` |
| 查看规则 | `/鲸鱼 wordle 规则` | `!鲸鱼 wordle 帮助` |

棋盘消息有「提交猜测」按钮，点击后弹出一个输入框；也可明确回复原棋盘消息并只填写一个五字母或七字母英文单词。🟩 代表字母与位置正确，🟨 代表字母存在但位置不同，⬛ 代表没有剩余的该字母可匹配。重复字母先计算绿格，再按答案中的剩余数量分配黄格。大小写不影响判定；长度错误、词库中没有的词、全频道已猜过的词都不扣次数。同一人两次有效猜测至少间隔三秒；多人同时提交会依次记入同一局。

每次有效猜测后，在本机用 Pillow 绘制小 PNG，更新**同一条棋盘消息**的附图，显示每条猜测、提交者与字母键盘状态，不调用图片生成模型或聊天 API。频道需要允许机器人 **Attach Files**（发送附件）；缺少权限、绘图或图片上传失败时会改用文字棋盘，猜测仍保存。若原棋盘被删除，「状态」会重新发送棋盘；发送消息权限暂不可用时也会保留进度，恢复权限后再查询。

每行猜测左侧显示提交者的圆形头像，格子下方保留昵称；优先使用该服务器内的专用头像。头像从 Discord 下载小尺寸静态图片，缓存于本机 `data/wordle-avatars/`，相同头像复用，不消耗模型 token。每条猜测保存头像快照，之后换头像不会改变旧记录；重启也可继续显示。头像读取超时、损坏或旧记录无法取得头像时使用默认人像，不影响猜词。旧记录如能从已缓存的服务器成员资料补到头像，会在下一次猜测或查询「状态」时更新。结束的游戏清理后，未被其他保留记录引用且缓存超过 30 天的头像会一并清理；这些图片不会发送给大模型或上传到源码仓库。

猜中或机会用完后揭晓答案并关闭输入按钮。提前结束只允许发起人、服务器管理员或本机指定的主人；进行中的游戏不能被别人重新开局覆盖。重启后恢复进行中的棋盘按钮与次数，旧一局的按钮或已打开输入框不能消耗新一局的机会。默认不设短倒计时，结束的记录保留 30 天。

Wordle 有独立开关，可在桌面配置的「本地功能」页调整，或用 `!鲸鱼 关闭功能 wordle` / `!鲸鱼 开启功能 wordle` 管理本服务器。关闭后不能开局或猜测，但仍可看状态、查看规则或由授权者结束。纯本地模式、聊天暂停或模型额度用完时仍可使用。猜词指令与棋盘不会进入自动聊天记忆或云端上下文。

英文词库随源码附带，运行时不联网查词：允许猜测的词库较大，答案候选来自更常用的分级词表；五字母和七字母各自独立。词表基于 [English Speller Database / ESDB](https://github.com/en-wl/wordlist) 生成，来源、固定版本、筛选方式和版权说明见 `wordlists/README.md` 与 `wordlists/ESDB-Copyright.txt`；采用独立随机答案，不接入 NYT 每日题目。游戏不含在线词义查询、排行榜或收费提示。

## 本地功能的保存与运行

“摸摸鲸鱼娘”“给鲸鱼娘喂饭”等明确动作也能本地回应，同一人十五秒内不会连续触发。普通的“吃饭”“困了”等群聊词不会触发本地互动。工具指令和回复会从近期云端聊天上下文中排除；近期本地结果上的“再来一次”也在本地处理，不启动收费续聊。每人每十秒最多处理六次本地操作；按钮三分钟内可用，过期可重新发命令。投票按钮独立保存，重启后仍能使用，七天后结束。

米饭、投票和群规始终按服务器隔离；便签和游戏另外按用户、频道隔离。签到按 UTC+8 零点换日。关闭“米饭签到”后，投喂不扣米饭，适合只想用简单互动的服务器。

提醒保存在本机 SQLite，每人每服务器最多 20 条待办，每约五秒检查一次。只在原频道发送，仅通知创建提醒的人，不通知其他用户、角色或全体成员。电脑关机、休眠、断网时无法发送，重新上线后补发并标明已到期；通信故障最多尝试五次，可用“提醒列表”查看失败条目。取消频道勾选、关闭对应功能会暂停发送，恢复后继续。生日与纪念日每年 UTC+8 09:00 提醒，发送后安排下一年；2 月 29 日仅在闰年提醒。提醒与日期功能可以分别暂停。

自备表情包可放在本机 `data/reactions/`：`feed.gif` 用于投喂，`pat.png` 用于摸摸。两类均支持 `.gif`、`.png`、`.jpg`、`.jpeg`、`.webp`，单文件不超过 4MB。没有图片时使用文字和当前服务器的表情。上传图片需要频道允许机器人 **Attach Files**。图片、个人便签、积分和提醒都不会发布到 GitHub。便签和提醒是主动创建的功能记录，独立于自动聊天记忆；请分别用删除便签、取消提醒等命令管理。

## 预算与隐私

默认每日**估算**上限为人民币 2 元，程序只使用其中 90%，留出 10% 余量；所有服务器和频道共用额度。普通插话另有每日 24 次及约 ¥0.4 的估算上限。每日预算、单价、币种和汇率可在配置窗口修改；输出长度和触发概率等高级设置仍在本机 `config.json` 中。新价格字段为 `pricing_currency`（`CNY` 或 `USD`）、`input_price_per_million`、`output_price_per_million`；旧配置的 `input_usd_per_million` 和 `output_usd_per_million` 仍可读取，保存时会迁移。估算使用配置中的价格和保守汇率，**不是供应商账单或平台硬限额**；供应商改价或同一密钥被其他程序使用时，实际花费可能不同。建议同时在供应商后台设置消费上限。

程序读取已选频道的少量近期文字消息以理解上下文，并将当前发言、相关上下文和检索到的记忆发送给配置的聊天模型供应商。启用自动记忆后，已选频道的文字消息、摘要、偏好和费用记录保存在本机 `data/whale.sqlite3`；本地总结调用 Ollama，不占云端 API 额度，但会使用电脑算力和电力。日志 `data/bot.log` 不主动记录聊天正文或密钥。`.env`、`config.json`、`data/` 和 `.venv/` 都不会进入 Git 仓库。清除本机记录不能撤回已发往供应商的请求或 Discord 上的原消息。

## 常见问题

- **@了不回：** 确认 `start.cmd` 窗口仍在、机器人已安装到该服务器、频道已在配置窗口勾选、Message Content Intent 已开启，并检查 `data/bot.log`。频道权限覆盖也可能挡住 View Channels、Send Messages 或 Read Message History。
- **只有 @ 才回：** 普通插话本来是概率触发；先用 `!鲸鱼 状态` 查看冷却和消息数。自然追问仅在同一位群友、同一频道、约两分钟的续聊窗口内判断。
- **配置后没变化：** 点击“保存并重启机器人”；仅保存配置不会让运行中的机器人重新加载。
- **换了 API 后报错：** 核对兼容入口的完整地址、模型名称、密钥及“附加参数”；`404` 可能是少了供应商要求的 `/v1` 等路径，`400` 常见于该接口不接受某个请求参数。模型列表不可用本身不妨碍聊天。
- **`401` 或无法登录：** 检查填的是 Bot Token 而非 Public Key；如曾泄露 Token，应在开发者后台重置，再更新本机 `.env`。
- **`403` 或频道不可见：** 检查机器人是否已安装到目标服务器，以及该频道的权限覆盖。配置窗口会在保存前尝试读取每个选定频道的历史。

## 开发与文件

核心代码：`bot.py` 处理 Discord 消息，`engine.py` 处理上下文、触发策略和模型调用，`provider.py` 校验自定义接口并构建兼容请求，`memory.py` 保存与检索自动记忆，`memory_worker.py` 调用本地 Ollama 并安排提醒，`storage.py` 保存手动记忆与费用。`local_tools.py` 提供本地运算，`local_features.py` 处理功能指令，`feature_store.py` 保存功能数据，`local_discord.py` 提供斜杠命令与按钮。`wordle.py` 保存合作游戏、判定字母并绘图，`wordle_discord.py` 管理棋盘消息和猜测弹窗。`setup_gui.py` 提供本机配置窗口，`settings.py` 校验配置。`config.example.json` 是可公开的模板；个人 `config.json` 和 `.env` 由配置窗口生成。

```powershell
.venv\Scripts\python.exe -X utf8 -m unittest -q test_bot test_memory test_provider test_local test_wordle
.venv\Scripts\python.exe -X utf8 check.py
# 下面这条会真实调用一次模型并计入当日预算：
.venv\Scripts\python.exe -X utf8 check.py --live
```
