Generated with ESDB's `scowl word-list` command:
- Allowed guesses: size 60, spellings `A,B,Z`, variant level 1, `--categories= --nosuggest`.
- Answer candidates: size 35, spelling `A`, variant level 1, `--categories= --nosuggest --poses=n,v,aj,av`.
- Retain only lowercase ASCII words of exactly five or seven letters. Answer candidates are intersected with allowed guesses. Words marked with the no-suggest suffix are excluded.

The dictionaries are bundled and never downloaded during gameplay. These are independently generated English lists, not the NYT answer list or a daily-puzzle feed.
